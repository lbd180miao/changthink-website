本项目是纯前端项目，用于展示网站的静态资源

如需增加AI推理、训练等具体服务，可自行反代并对接后端服务器

拉取项目后，使用前端命令安装环境

```sh
# 安装依赖
pnpm i

# 启动程序
pnpm astro dev

```

然后准备一下开发环境，以及 Vibe Coding 环境

我们使用的前端框架的 MCP
- [Astro MCP](https://docs.astro.build/en/guides/build-with-ai/)：直接用
- [DaisyUI MCP](https://daisyui.com/docs/editor/claudecode/)：推荐使用 Context7 MCP

```sh
# 自己的 Claude Code 也准备好插件
/plugin install frontend-design@claude-code-plugins
```
