# Astro项目协作规范 - 所有AI必须遵守

本项目为降低门槛，暂时没有引入CI脚本，如果发现项目维护性变差，会考虑引入

## 样式规范（强制）
- 每次生成<style>标签时，必须加上 scoped 属性：<style scoped>
- 禁止生成全局样式，除非用户明确要求

## DOM操作规范（强制）
- 禁止使用 document.getElementById、document.querySelector、document.addEventListener
- 需要客户端交互时，必须封装成独立的Preact/Vue组件，然后用client:load引入

## 依赖规范（强制）
- 新增任何依赖前，必须询问用户并说明理由
- 目前团队前期会先讨论具体使用的框架，后期避免修改

## 通信机制（强制）
不允许三个以上岛屿组件互相传递事件。
如需复杂通信，统一升级为 nanostores
原因：避免出现"事件链地狱"，难以调试

## 图片规范（推荐）
- 图片推荐使用 <Image /> 组件（import { Image } from 'astro:assets'）
- <img> 标签仅用于部分不可控图片、大批量图片等加载时进行处理

## 内容集合的类型安全（推荐）
- 如果团队开始写博客或产品列表，尽早引入
- 所有 src/content/ 下的集合必须在内容层定义 Schema，
- 避免 MD 文件缺字段导致构建失败
